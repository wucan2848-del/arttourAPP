# 艺所地图 ArtTour — 团队协作指南（3 人）

> 仓库地址：https://github.com/wucan2848-del/arttourAPP  
> 每人只需 **clone 一次**；之后循环 **pull → 改 → commit → push**。

---

## 一、开始前准备（每人做一次）

| 需要安装 | 下载 |
|----------|------|
| Git | https://git-scm.com/download/win |
| Node.js 20+ | https://nodejs.org |

1. 注册 GitHub 账号，把用户名发给负责人  
2. 在邮箱里 **接受** 仓库协作邀请  
3. 第一次下载项目：

```powershell
git clone https://github.com/wucan2848-del/arttourAPP.git
cd arttourAPP
npm install
npm run dev
```

浏览器打开 **http://localhost:5173**，能看到页面 = 环境 OK。

---

## 二、日常开发（每次改代码都按这个来）

```
① pull（先同步队友的改动）
② 开分支（不要直接在 main 上改）
③ 改代码 + 本地测试
④ commit + push
⑤ 在 GitHub 提 Pull Request，合并进 main
```

### 命令版（复制即用）

```powershell
cd arttourAPP

git pull origin main                              # ① 同步最新代码

git checkout -b feature/简短描述                  # ② 开分支，例：feature/添加东京馆
# ……改代码，npm run dev 本地看效果……

git add .
git commit -m "做了什么（一句话）"
git push origin feature/简短描述                  # ④ 上传你的分支
```

### 第 ⑤ 步：提 Pull Request（网页操作）

1. 打开 https://github.com/wucan2848-del/arttourAPP  
2. 点黄色条 **Compare & pull request**  
3. 写清楚改了什么 → **Create pull request**  
4. 另一人看一眼 → **Merge pull request**  
5. 合并后，大家下次开发前再 `git pull origin main`

## 三、分工建议（减少改同一文件）

| 目录 / 文件 | 适合谁改 |
|-------------|----------|
| `src/pages/`、`src/components/` | 界面、交互 |
| `src/data/museums.ts`、`src/data/cities.ts` | 美术馆 / 城市数据 |
| `src/App.tsx`、路由相关 | 与负责人先商量 |
| `public/images/` | 图片资源 |

**原则：** 改前先 `pull`；尽量别 3 人同时改同一个文件。

## 五、常见问题

| 问题 | 处理 |
|------|------|
| `npm install` 报错 | 确认 Node.js 20+；删 `node_modules` 后重装 |
| push 要用户名密码 | 密码处填 **Personal Access Token**（GitHub → Settings → Developer settings → Tokens） |
| 提示冲突（conflict） | 先 `git pull`，按提示选保留哪段代码，再 commit、push |
| 改错了想撤销 | 未 commit：`git checkout .`；已 push：联系负责人 |

---

## 六、一句话记住

> **改前 pull，改完 push，合并用 Pull Request，不要直接在 main 上改。**

有问题在仓库 **Issues** 里提问，或群里 @负责人。
